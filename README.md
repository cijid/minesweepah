# minesweepah
This application is my attempt at a Minesweeper clone.

# About Minesweeper
Minesweeper is a logic puzzle video game. The objective is to clear the board without detonating any mines, using clues about the number of neighboring mines in each field - [Wikipedia](https://en.wikipedia.org/wiki/Minesweeper_(video_game))

# Gameplay
Each cell has three states: unopened, opened, and flagged
Unopened – blank and clickable
Opened – exposed and unclickable
Flagged – marked by the player to indicate a potential mine

Player selects a cell to open it with left mouse click.
If it contains a mine, the game ends.
Otherwise, the opened cell displays either a  number or zero to indicate the number of mines vertically, horizontally, or diagonally adjacent to it.
All adjacent empty cells are opened automatically.

## To win:
All non-mine cells must be opened without opening a mine.
